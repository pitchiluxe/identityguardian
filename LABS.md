# IAM simulation labs

Planned. Attempts clone versioned synthetic scenarios into learner-only environments. Reset affects only that attempt. Retain configuration submissions, validator results, hints and reports; no production connectivity.

| Lab | Validation goal |
|---|---|
| Onboarding | Approved baseline and correct department/manager |
| Password reset | Target scope and simulated identity verification |
| Account lockout | Diagnose cause and valid unlock policy |
| Group management | Intended membership change only |
| RBAC | Exact required actions with least privilege |
| MFA registration | Simulated method satisfies rubric; no real secret |
| Conditional access | Positive and protected negative cases |
| SSO configuration | Simulated issuer/audience/attribute mapping |
| Access review | Evidence decision and approved removal proposal |
| Privileged access | Justification, duration, independent approval, expiry |
| Service account governance | Owner, scoped permissions, credential lifecycle |
| Termination | Account/session/token/ownership dependencies |
| Role transfer | Retain/review/remove without destroying justified grants |
| Privilege creep | Explain previous-role lineage |
| Incident investigation | Historical evidence and coverage |
| Attack path | Conditional route and defensive controls; no exploit |

Rubric: correctness 50%, least privilege 25%, evidence/workflow 25%. Safety failures prevent passing regardless of total. Store rubric version and negative cases. Ollama explains validator findings and provides progressive hints; cannot edit configuration or award scores. Offline hints are explicitly deterministic. Report includes changes, outcomes, evidence, hints, score and misconceptions.
