ⓘThis page is a showcase. The platform itself runs locally (FastAPI, PostgreSQL, Keycloak and a background worker) with a synthetic organization. It makes no production connections and no real IAM changes.
Capabilities

Investigate → explain → simulate → approve

Each capability below is implemented and covered by automated tests. All data shown is synthetic.

Effective access lineage

Every direct, nested, conditional and denied route to an entitlement, with the source evidence for each hop.

Exposure paths

Defensive, bounded analysis of how an identity could reach sensitive resources, and which controls apply.

Time machine

Bitemporal history: what access looked like at a moment, as known then and as known now.

Independent approval

Role and access changes are bound to a digest and version, approved by a second person with recent MFA, and then executed in a sandbox.

Policy-as-code

Typed, validated policies with tests and impact simulation. A policy is approved before it is activated, and flags never silently revoke access.

Grounded local AI

An optional Ollama investigator that answers only from authorized evidence, with verified citations. It has no execution authority.

Tenant isolation

PostgreSQL row-level security on every tenant table, separate database roles, and membership checks on every request.

Tamper-evident audit

An append-only, hash-chained audit trail with Ed25519-signed checkpoints for off-platform storage.

IAM labs

Isolated lab environments with rubrics, progressive hints and deterministic scoring for hands-on IAM training.

Status

Honest status

  • Built and tested locally: 21 phases, from OIDC sign-in, tenant isolation and approvals through graph analytics, AI, policy, labs, reporting, hardening, performance, packaging and invite-based registration.
  • Not production-accepted: an independent penetration test, a production identity provider, KMS-managed keys and off-site backups are still open gates.
  • Connectors: only mock and sandbox providers. Real identity systems are never contacted.
